### 什么是JJ？
JJ（即Jujutsu）是一个还算新鲜的VCS工具，我是在朋友的推荐下进行了尝试。实际上，初次使用的体验很怪，但不得不承认的是操作确实很简单。

### 安装
直接用**scoop install**即可

`scoop install jj`

什么？你说你没装scoop？
在PowerShell运行：

`irm get.scoop.sh | iex`

### 开始使用

在项目目录下打开powershell，用这个命令来进行初始化

`jj git init --colocate`

然后跟着指引配置你的邮箱（注册Github使用的邮箱）和用户名（你的Github User Name 或者昵称都可以）

如果不习惯命令行，可以装一个VScode扩展：

Jujutsu Kaizen

### 提交一个更改

 jj 的工作副本是一个自动提交的 commit，所以不需要像 Git 那样先 git add 再 git commit。工作副本的变更会自动被快照，再用 jj describe 添加描述信息。

作一些改动，然后

`jj desc -m "你对于这些改动的描述 也就是Git的commit message"`

然后就可以

`jj git push`

推送到远程仓库

然后我们就可以移动到新的 工作副本进行接下来的改动

`jj new`

以此创建一个新的工作副本

或者你可以在改动完后把 describe 和 new 操作用 commit 命令一起完成：

`jj commit -m "你对于这些改动的描述 也就是Git的commit message"`

### 撤销操作

jj 最大的好处是，你几乎可以撤销任何操作。如果你不小心提交错了，或者想把仓库恢复到上一步的状态，只需要：

`jj undo`

这是 jj 的核心特性之一——操作日志让你可以撤销几乎任何操作，可以连续撤销多次。

### 什么是工作副本？

这是jj中一个极其重要的概念，你可以把它理解为一个可更改的commit
